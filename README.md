# Football-Player-Tracking-Analysis ⚽

Football Player Tracking and Analysis is a computer vision project using Python, YOLO, and OpenCV to detect and track objects in football videos. It analyzes tracking IDs, movement trajectories, estimated speeds, and detection counts, with results visualized using graphs and an analytics dashboard.

## Technologies Used
- Python
- YOLO (Ultralytics)
- OpenCV
- Pandas and NumPy
- Matplotlib
- Google Colab

## Features
- Object detection and tracking with IDs
- Bounding boxes displayed on the output video
- Tracking data exported to CSV
- Movement trajectory visualization
- Estimated movement speed analysis
- Detection count analysis
- Analytics dashboard with graphs

## Project Files

- `Football_Player_Tracking_Analysis (1).ipynb` — Google Colab notebook containing the project code
- `player_tracking_data (1).csv` — Detailed tracking records
- `player_tracking_summary.csv` — Summary of tracking IDs and estimated speeds
- `football_analytics_dashboard (2).png` — Analytics dashboard with graphs

## 🎥 Tracked Football Video

The processed football video demonstrates player detection and tracking using YOLO and OpenCV. Bounding boxes and tracking IDs are displayed on detected players throughout the video.
